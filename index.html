MySQLSQLER 모델관계형 데이터베이스2인 팀

FlightDelayDB

📅 2025년 12월 · 2학년 데이터베이스 수업 과제

날씨, 항공사, 성수기, 시간대와 공항 혼잡도 등 항공편 지연에 영향을 주는 요인을 통합 관리하고 SQL로 분석하는 데이터베이스 프로젝트입니다. 항공편과 과거 지연 기록을 연결해, 사용자 항공권의 조건에 따른 지연 경향을 조회할 수 있도록 구성했습니다.

역할 분담

  • 친구와 2인 팀으로 진행했으며, 기획과 SQL 코드 작성을 담당했습니다.
  • 팀원은 영어 논문 작성을 담당했습니다. 데이터베이스 구현과 영어 논문 제출이 함께 요구된 수업 과제였습니다.

설계와 구현

  • 항공편을 중심으로 항공사·공항·기체·기상·시즌·지연 이력·사용자 항공권의 관계 설계
  • MySQL 테이블 생성과 기본키·외래키·UNIQUE 제약을 적용한 데이터 무결성 관리
  • 항공편과 기상 데이터의 다대다 관계를 매핑 테이블로 구성
  • JOIN·서브쿼리·AVG·COALESCE를 활용해 요인별 평균 지연시간과 합산 결과 조회
  • 샘플 데이터 입력과 외래키 오류·중복 입력 방지·항공권 기반 분석 결과 검증

교육용 샘플 데이터를 바탕으로 관계형 모델과 분석 쿼리를 검증한 프로젝트입니다. 실제 운항을 예측하는 서비스로 배포한 단계는 아니며, 복합적인 문제를 데이터 구조와 SQL로 표현하는 경험을 쌓았습니다.

에브리타임 키워드 집계

📅 2026년 4월 · 신문사 기자의 요청으로 제작

서울과기대신문사 활동 중 기사에 사용할 에브리타임 단어 수를 집계해야 하는 상황이 있었습니다. 200개가 넘는 단어를 사람이 일일이 세기 어려워, 해당 기사를 담당하던 기자분의 부탁으로 크롤링 프로그램을 만들었습니다.

구현 내용

  • Selenium으로 Chrome을 제어하고, 사용자가 직접 로그인한 뒤 지정한 키워드의 검색 결과 수집
  • 스크롤과 페이지 순회로 게시글을 추가 로딩하고 게시 날짜 추출
  • 지정한 날짜별로 키워드 검색 결과의 게시글 수 집계
  • pandas로 날짜·개수 데이터를 정리해 CSV 파일로 저장
  • 검색 키워드, 집계 날짜, 페이지 범위와 출력 파일명을 명령행 옵션으로 지정

실제 기사에 활용된 결과

  • 집계 결과는 서울과기대신문의 STU 사업 관련 기사에 학생들의 관심 변화를 설명하는 근거로 사용됐습니다.
  • 기사에서는 2026년 1월부터 3월 16일까지 ‘시위’ 키워드 언급량이 8건, 3월 17일부터 31일까지는 593건으로 약 74배 증가했다고 제시했습니다.

기자가 수작업으로 확인해야 했던 반복 집계를 자동화하고, 학생들의 관심이 높아졌다는 해석을 뒷받침할 수치 자료를 제공했습니다. 프로그램의 결과가 실제 보도에 반영되면서, 취재 과정의 자료 수집과 근거 제시에 기여한 프로젝트입니다.

📅 2026년 5월 · 개인 프로젝트 · 직접 기획·개발

서울과기대신문사 기자로 활동하며 기획회의와 기사 작성에 필요한 과거 기사를 자주 찾아야 했습니다. 공식 홈페이지에서 원하는 기사를 찾기 어렵고 가독성이 아쉽다고 느껴, 같은 불편을 겪는 기자들이 기사를 더 쉽게 탐색할 수 있는 검색 서비스를 직접 제작했습니다.

해결하려던 문제

  • 검색 결과가 관련도보다 최신순으로 표시돼 주제를 중점적으로 다룬 기사를 찾기 어려웠습니다.
  • 오래된 기사가 누락되거나, 내용을 확인하려고 기사를 하나씩 열어봐야 하는 불편이 있었습니다.
  • 629~715호의 기사 1,166개를 검색과 탐색에 활용할 수 있도록 데이터를 구축했습니다.

주요 기능과 기술

  • Python으로 기사 데이터를 처리하고, HTML·CSS·JavaScript와 D3.js로 검색 화면과 네트워크 그래프 구현
  • 제목·본문의 검색어 등장 빈도로 관련도 계산, 관련도가 높은 기사일수록 큰 노드로 표시
  • TF-IDF 키워드와 코사인 유사도로 내용이 비슷한 기사들을 연결
  • 기사의 주요 키워드를 워드클라우드로 미리 확인하고 공식 홈페이지 원문으로 이동
  • 기사 카테고리 필터와 전체 검색 결과의 언급순·최신순 정렬
  • GitHub Actions · GitHub Pages를 활용한 웹 배포

모바일 개선과 실제 활용

  • 처음에는 PC 중심으로 개발했지만, 스마트폰에서 UI 배치와 그래프 조작의 불편을 직접 확인했습니다.
  • 화면 크기에 맞는 UI, 터치로 기사 키워드 확인, 그래프 이동과 두 손가락 확대·축소를 지원하도록 개선했습니다.
  • 신문사 기자들의 기획회의와 기사 작성 과정에서 활용했습니다.
