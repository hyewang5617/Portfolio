# Pre-SKALA 포트폴리오 작성 근거

2026-10-12 확인. 포트폴리오는 지원자 경험을 설명하는 문서이며, 프로그램 수료·수상 또는 Agent 서비스를 이미 구축했다는 주장은 하지 않는다.

## 지원 대상과 강조점

- 사용자 최초 링크 `https://www.2026skala.co.kr/`는 웹 조회에서 403 반환. 해커톤 모집 안내를 검색한 후 실제 공식 사이트 `https://2026pre-skala.co.kr/`를 브라우저로 확인했다.
- Pre-SKALA는 직접 문제를 정의하고 AI로 답을 만드는 프로그램이다. 온라인 과정은 Agent 이해·업무 분석, 바이브코딩, AI 지시·결과 검증, 도구 연결·실행·테스트·개선을 포함한다.
- AI 해커톤은 온라인 과정 우수 수료자 100명에게 참여 기회를 제공한다. 일반 SKALA 교육과 Pre-SKALA 해커톤 안내를 혼동하지 않는다.
- 사용자가 준 영상 `https://www.youtube.com/watch?v=kmlkeKsVffg`의 한국어 자동 자막을 내보내 확인했다. 기술 단독 구현보다 현업 문제, 서비스 전체 구현, 역할 분담과 배포를 강조하는 맥락을 참고했다. 영상은 정규 SKALA 설명이므로 Pre-SKALA의 직접 선발 기준으로 단정하지 않았다.

- Sportly: 인증·권한·알림 소유자 조회, 평점 수정 시 차이 반영 로직으로 구현 깊이를 설명. `C:/Users/Administrator/study/node.js/soccer-matching/src/services/rating.service.ts`, `notification.service.ts`, `middlewares/auth.ts`, `controllers/phone.controller.ts`를 확인. 회의 리딩·API 문서화와 배포 경험은 기존 사용자 설명과 포트폴리오 HTML을 근거로 작성. 프론트엔드 통합 미완료를 명시. 동시성·트랜잭션 안전성을 보장한다는 주장은 하지 않음.
- 기사찾기: 사용자 제작일 정정에 따라 2026년 5월. 1,166개 기사, TF-IDF·코사인 유사도·검색 빈도·D3.js는 기존 포트폴리오 설명과 제공 PDF를 근거로 작성. 검색 관련도와 문서 유사도를 구분하고 LLM/RAG 서비스라고 부르지 않음.
- Cooking Papa: `C:/3학년/정혜원_포트폴리오.pdf` 7~8쪽의 직접 구현·문제 해결 내용 및 원본 화면 사용. MediaPipe 모델을 직접 학습했다거나 정확도·처리속도 수치를 측정했다는 주장은 하지 않음.

## 시각 검증 (2026-10-12 카드형 개정)

- 960×600 가로 페이지, 본문 주로 20~23pt, 제목 34~44pt.
- 검정·흰색 중심, 연두색 강조. 실제 화면의 원래 색상 유지.
- 사용자 제공 2.png~9.png 및 json_thumb.png의 카드형 레이아웃, 검정 캡슐 라벨, 큰 제목과 은은한 배경 그라데이션을 반영. 강조색은 기존 요청대로 연두색 유지. 샘플의 인물·경력·숙련도 수치·성과 그래프는 사용하지 않음.
